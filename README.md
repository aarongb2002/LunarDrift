# LunarDrift

An elegant, modern native streaming app.
Compatible with iOS (Sideloading), Android, MacOS, Windows and online at https://lunardrift.watch

## Getting Started

We are getting very close to launch, but for now the iOS version is fully functinal. 

## iOS (Sideloaded)
You can use iLoadly to sideload SideStore (stable) and then use that alongside LocalDevVPN and Actions (on the app store) with a shortcut turned automation to install the app via .ipa and permanentaly install it.
